## 9.2 0.1.2 变更明细

**新增能力**

- 底部文字按钮**默认每排三个**（此前每排两个）；四个时平均分两排、各两个；一排里只剩一个时占半排居中。
- 新增 `ButtonLayout` 与 7 个卡片构建器上的 `setButtonLayout`：每排 1~4 个、一排里的分宽方式（等分 / 主要或带自定义底色的按钮占两份 / 按文字长短）、只剩一个时的占宽（半排 / 整排 / 按文字长短）与对齐（靠左 / 居中 / 靠右）。语义见 [`04-SDK接口参考.md`](04-SDK接口参考.md) §4.9。
- 线格式新增 `buttonLayout` 扩展（`perRow` / `rowFill` / `loneFill` / `loneAlign`），见 [`03-通信协议.md`](03-通信协议.md) §3.4。

**兼容性**

- 更新了接口说明与示例工程，示例中用三个文字按钮演示新排法。
- **旧版星河岛读不到该设置**，仍按每排两个排，不会报错。也就是说接 0.1.2 的库在旧宿主上「能跑但排法退化」，属预期行为。
- 从 0.1.1 升级：**替换工具包文件与依赖文件名即可**，公开接口没有破坏性变更（0.1.1 的类清单是 0.1.2 的子集，0.1.2 只多出 6 个 `ButtonLayout*` 类）。

**未变化的**

- 通信版本仍为 7；清单声明、权限名、四类按钮、九个卡片模板、结果码与全部数值上限均无变化（`02` §2.2、`06` §6.1）。

## 9.4 历史版本要点（只作背景）

**0.1.1**：公开接口与 0.1.0 相同；连接前**严格核对通信版本**，不接受未知的高版本宿主；明确回复期间保护、外部内容名额（3 条）与连续更新的提醒行为。

**0.1.0**：首个公开测试版，确立至今未变的基本形态——

- 类型化接口在 `com.astraisland.sdk`：`IslandClient`、`IslandActivity`、`Capsule`、`IslandCard` 及九个子类、按钮类型、回调。
- 九套模板：通用、进度、强调、明细、状态、大图、音乐、消息、对称（[`05-卡片数据结构.md`](05-卡片数据结构.md)）。
- 按钮：文字按钮最多 4 个，另有圆形图标按钮、底部图标按钮与开关；文字按钮支持主要/破坏性样式与自定义底色。
- 进度卡片支持阶段名称（2~16 个）。
- 回调：`onDismissed`、`onExpanded`、`onCollapsed`、`onEnded`。
- 结果以枚举 `IslandResult` 返回；写法错误在**构造时**抛 `IllegalArgumentException` 并附中文说明。
- 锁屏仅显示标题时，码、明细、比分、标签与阶段名一并隐藏（[`04-SDK接口参考.md`](04-SDK接口参考.md) §4.5）。

## 9.5 从 0.1.1 升到 0.1.2 的操作清单

1. 用 `astraisland-sdk-0.1.2.aar` 替换 `libs/` 下的 0.1.1 文件，并同步改依赖文件名（`implementation(files("libs/astraisland-sdk-0.1.2.aar"))`）。
2. 校验产物：169,504 字节、sha256 `1e7f71caad0097e5be908420183eaf7826ae364b9bf64d4a436977833af01f14`（见 [`README.md`](README.md)）。
3. 代码无需改动即可编译；想用新排法再加 `setButtonLayout(ButtonLayout(...))`。
4. 清单不用动（AAR 的声明与 0.1.1 完全一致，[`02-接入与清单.md`](02-接入与清单.md) §2.2）。
5. 回归重点：底部文字按钮的排法（默认从每排两个变成每排三个）、四个按钮时的两排分布、只剩一个按钮时的位置。

## 9.6 版本号与通信版本的区别

| 概念 | 取值 | 谁在意 |
| --- | --- | --- |
| **SDK / 工具包版本** | `0.1.2`（`IslandClient.SDK_VERSION`） | 开发者：换包、看变更 |
| **通信版本** | `7`（`IslandClient.PROTOCOL_VERSION`、`IslandProtocol.PROTOCOL_VERSION` 与 `MIN_PROTOCOL_VERSION` 均为 7） | 宿主与客户端握手：**只认这个**，低于或高于 7 都不连接 |

所以「SDK 升级到 0.1.3」不会改变通信版本，也不代表宿主必须升级；反之宿主通信版本不是 7 时，装哪个 SDK 都没用（[`07-错误码与排查.md`](07-错误码与排查.md) §7.2）。
