## 8.1 连接与线程骨架

```kotlin
class MainActivity : Activity() {
    private lateinit var client: IslandClient
    private val worker = Executors.newSingleThreadExecutor()   // 所有阻塞调用放这里

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        client = IslandClient(this)
        client.setCallback(callback)
        client.connect()                                       // 主线程只做连接
    }

    /** 后台提交，结果回主线程。 */
    private fun run(block: () -> Any) {
        worker.execute {
            val result = block()
            runOnUiThread { append("结果：$result") }
        }
    }

    override fun onDestroy() {
        client.disconnect()          // 会结束本应用全部内容，见 06 §6.2
        worker.shutdown()
        super.onDestroy()
    }
}
```

回调默认都在主线程，按需重写即可：

```kotlin
private val callback = object : IslandCallback() {
    override fun onStateChanged(state: IslandClient.State) = append("状态：$state")

    override fun onAction(activityId: String, actionId: String) {
        when (actionId) {
            TimerControl.PAUSE.actionId -> show("timer", pausedTimer())
            TimerControl.RESUME.actionId -> show("timer", emphasisTimer())
            TimerControl.STOP.actionId, StatusCard.ACTION_STOP -> run { client.end(activityId) }
            MediaControl.PLAY_PAUSE.actionId -> show("music", media(playing = false))
        }
    }

    override fun onReply(activityId: String, text: String) = append("回复：$activityId / $text")
    override fun onSeek(activityId: String, positionMs: Long) = append("拖动：$activityId / $positionMs")
    override fun onDismissed(activityId: String) = append("用户划走：$activityId")
    override fun onEnded(activityId: String, reason: EndReason) = append("结束：$activityId / $reason")
}
```

> `onDismissed` 只在用户**手动划走**时来；用户开「长时间未操作时收起」「停留后收起」导致的自动收起**不回调**（[`06-生命周期与配额.md`](06-生命周期与配额.md) §6.5）。

## 8.2 最小可用示例

```kotlin
// 后台线程
val capsule = Capsule.Builder(IslandImage.appIcon())
    .setTrailing(CapsuleTrailing.text("进行中"))
    .build()
val card = GenericCard.Builder("文件同步")
    .setSubtitle("3 个文件")
    .build()
val activity = IslandActivity.Builder("sync", capsule, card).build()
when (val r = client.start(activity)) {
    IslandResult.OK -> {}
    IslandResult.NOT_CONNECTED -> client.connect()   // 等 READY 后重试
    else -> log("失败：$r")                          // 语义见 07 §7.1
}
```

- 这段在示例工程 `MainActivity.kt:190` 附近，是唯一用 `ButtonLayout` 的地方；`perRow = 3` 与 0.1.2 的默认值相同，写出来只是为了演示。

```kotlin
    .setPostedAt(System.currentTimeMillis())     // 只在收到新消息时更新，否则不重新占据主岛
    .setOwnNotification(notificationId, tag)     // 关联自己的通知
    .setLockScreenVisibility(LockScreenVisibility.TITLE_ONLY)
    .build()
```

```kotlin
override fun onAction(activityId: String, actionId: String) {
    if (activityId != "chat-xiaoming" || actionId != "mark_read") return
    markConversationRead("xiaoming")            // 应用自己标已读
    // 之后可用同一编号 update：去掉按钮、换标题等
}
```

`mark_read` 是**示例自定义编号**，不是系统保留操作；星河岛不会据此自动把会话标为已读（[`05-卡片数据结构.md`](05-卡片数据结构.md) §5.12）。

## 8.6 强调卡片：取件码与计时

```kotlin

private val timerEnd = System.currentTimeMillis() + 25 * 60_000L

EmphasisCard.Builder("专注", EmphasisValue.countdown(timerEnd))
    .setSubtitle("第 2 轮")
    .setBody("结束后休息 5 分钟")
    .addControl(TimerControl.PAUSE)
    .addControl(TimerControl.STOP)

    .setSubtitle("已暂停")
    .addControl(TimerControl.RESUME)
    .addControl(TimerControl.STOP)
```

## 8.9 结束、收尾与状态查询

```kotlin
client.end("progress", Outro(true, "下载完成"))   // 约 1.6 秒的收尾，仅当内容仍在岛上
```

## 8.10 Java 调用

```java
IslandClient client = new IslandClient(context);
client.setCallback(new IslandCallback() {
    @Override public void onAction(String activityId, String actionId) { }
    @Override public void onEnded(String activityId, EndReason reason) { }
});
client.connect();

Capsule capsule = new Capsule.Builder(IslandImage.appIcon())
        .setTrailing(CapsuleTrailing.text("¥12"))
        .build();
GenericCard card = new GenericCard.Builder("停车计费")
        .setSubtitle("B2 层 052 号")
        .setImage(IslandImage.symbol(BuiltinSymbol.INFO))
        .addButton(new TextButton("pay", "缴费", ButtonStyle.PRIMARY))
        .build();
client.start(new IslandActivity.Builder("parking", capsule, card).build());   // 后台线程
client.end("parking", new Outro(true, "已缴费"));
```

要点：Kotlin 属性在 Java 中为 `getXxx()` / `isXxx()`；带默认值的参数由 `@JvmOverloads` 生成重载，所以 `new TextButton("pay", "缴费")` 合法；静态工厂（`IslandImage.picture()`、`CapsuleTrailing.text()`、`DismissPolicy.untilEnded()`）是静态方法。

## 8.12 常见改错

| 写法 | 问题 | 正确做法 |
| --- | --- | --- |
| 主线程直接 `client.start(...)` | 阻塞 UI，可能 ANR | 放后台线程，结果回主线程 |
| 每次刷新都改 `setPostedAt` | 消息卡片被当成新消息反复抢占主岛 | 只在真收到新消息时更新发送时间 |
| 计时每秒 `update()` | 触发 `RATE_LIMITED` | 用 `CapsuleTrailing.countdown` / `EmphasisValue.countdown` 让宿主走 |
| 更新时换了新编号 | 变成两条内容，占配额且动画断裂 | 同一事项固定同一编号 |
| 用 `IslandImage.appIcon()` 做卡片图片 | 运行时抛 `IllegalArgumentException` | 卡片用 `picture` / `glyph` / `symbol`，`appIcon` 只用于胶囊与副岛 |
| 把 `mark_read` 当系统保留操作 | 点了不会自动已读 | 自己在 `onAction` 里处理（§8.5） |
| 依赖 `onDismissed` 判断「用户不要了」 | 自动收起不回调，会漏判 | 用 `end()` 控制生命周期，收起只是显示状态 |
