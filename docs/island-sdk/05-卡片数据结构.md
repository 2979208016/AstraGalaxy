# 05 · 卡片数据结构

> 来源：`[站点]` <https://astraflow.cc/island/develop-api.html>（九种卡片的字段与异常）、`design-capsule.html`、`design-card.html`、`design-type-color.html`（结构与尺寸）；与 `[SDK]` `astraisland-sdk-0.1.2.aar` 字节码一致。
>
> 本文件只讲**数据结构与呈现**。构造器方法签名汇总见 [`04-SDK接口参考.md`](04-SDK接口参考.md)，卡片选型见 [`01-概述与环境.md`](01-概述与环境.md) §1.3。一条内容 = 一个 `Capsule` + 一个 `IslandCard`，由 `IslandActivity` 组合。

## 5.1 胶囊

胶囊是默认形态，以摄像头为中心显示一至两项信息。由五部分组成，应用只提供内容，位置、尺寸、对齐由星河岛统一处理：

| 组成 | 说明 | 来源 |
| --- | --- | --- |
| 左侧图像 | 内容自己的图像（封面、头像、商品图）或内置符号；未提供时显示应用图标 | 应用提供（`Capsule.Builder(leading)`） |
| 左侧标签 | 图像右侧的简短状态文字，可省略 | 应用提供（`setLabel`） |
| 摄像头 | 中心，两侧内容以此对称 | 星河岛 |
| 右侧内容 | 一条文字、数值、计时，或进度环、加载指示、波形 | 应用提供（`setTrailing`） |
| 尾部图标 | 右侧文字后的附加元素，如电池图标或电量环，可省略 | 应用提供（`setTail`） |

各字段的类型与默认值见 [`04-SDK接口参考.md`](04-SDK接口参考.md) §4.6，此处只讲显示规则。

- **对称布局**：以摄像头为中心左右对称，两侧伸出长度相同，由内容较长的一侧决定。仅文字参与居中——左侧标签在图像与摄像头之间居中，右侧文字在摄像头右侧区域内居中；图像、进度环、波形固定在两端。带尾部图标时，尾部图标固定右端，文字在其与摄像头之间居中。
- **长度**：竖屏长度由摄像头、留白与内容共同决定，夹在「最短长度」（默认 0%，按内容收窄）与「最长长度」（默认屏幕宽度 62%，可调 50%~80%，所有胶囊共用）之间；横屏不受这两项影响。无内容可显示时收窄为刚好放一个小图标的最小形态。
- **左侧**：仅提供文字时显示卡片主图；无主图时显示应用图标，文字作为左侧标签。
- **右侧**：有文字时持续显示，其后最多一个尾部图标。计时始终完整显示——宽度不足时先加宽（不超过屏幕宽度 80% 与副岛的让位范围），仍不足时缩小字号至最小 75%。右侧无文字时可显示进度环、加载指示或波形。
- **文字不截断**：右侧文字不会以省略号收尾，请给简短、确定的文字或数值；横屏可用 `setLandscapeText` 另给一段（≤32 字符，数字与英文按组竖排后须在四行以内）。
- **文字颜色**：默认白色，用户可在星流「外观」页更改。带固定含义的颜色不随设置改变——来电与通话 `#30D158`、其他来源的计时 `#FF9F0A`、录制 `#FF453A`；外卖、打车、快递、导航等事项的右侧文字使用来源应用的强调色，左侧保持白色。

### 副岛

多个事项同时存在时，优先级最高的作主岛，其后的一至两个事项以圆形显示在主岛两端。副岛只显示一个元素（头像、封面、应用图标或进度环），**不显示文字**，用的是胶囊的左侧图像或右侧进度环；无主岛时不单独显示副岛。点按副岛或沿胶囊方向滑动可切换为主岛，能否成为主岛由优先级决定（[`06-生命周期与配额.md`](06-生命周期与配额.md) §6.4）。

## 5.2 展开卡片的结构

卡片由八个固定区域组合而成，各模板只是取用其中若干：

| 区域 | 说明 |
| --- | --- |
| ① 来源栏 | 用户开启「显示应用来源」时由星河岛写入应用图标与名称，应用不能修改；有发送时间时右侧写时间。该开关默认关闭，规则见 [`04-SDK接口参考.md`](04-SDK接口参考.md) §4.8 |
| ② 主图 | 内容自己的图像；显示来源栏且仅有应用图标时不显示 |
| ③ 标题 | 最突出的信息；强调模板中为关键信息上方的一行说明 |
| ④ 副标题 | 标题下方一行 |
| ⑤ 关键信息 | 最重要的一项数值或文字，大字号（计时、取件码、比分） |
| ⑥ 右侧区域 | 放大数值、圆形按钮、单个胶囊按钮、进度环或波形，**只显示其中一项** |
| ⑦ 正文 | 副标题下方，最多两行 |
| ⑧ 底部区域 | 进度条、明细、大图、按钮组或回复栏，**只显示其中一项** |

### 位置与尺寸（单位 dp）

- 默认包围摄像头：卡片自胶囊上沿展开，摄像头在顶部黑色区域内；用户可在「布局与动画」页改为「在摄像头下方」，此时自状态栏下方展开，来源栏显示在卡片第一行。
- 卡片下沿留白 16；在摄像头下方及横屏时上沿留白 16；圆角跟随屏幕圆角（屏幕圆角减卡片与屏幕边缘距离，范围 24~36）。
- 主图 44（非方形按原比例，最宽为高度的两倍）；大图宽度与卡片一致、最大高度 140、圆角 14；进度条粗细 6、两端圆角。

### 颜色

- 每个事项有各自的强调色：优先用应用指定的颜色（`setAccentColor`），未指定时取应用图标主色（接近黑白灰的图标不取色），过暗会被提亮。强调色用于**主要按钮、进度条、放大数值**，不用于卡片表面。
- 音乐卡片光效跟随封面颜色（用户关闭「卡片使用封面色调」或封面无法取色时为白光）；系统服务提供底色时（外卖、打车、导航、气象预警）卡片背景按该底色着色，光效仍为中性白；其他卡片中性白光效。

## 5.3 通用 `GenericCard`

左侧图片，标题（右侧可放大一项数值或时间），说明一行，正文最多两行，底部按钮。

| 方法 | 说明 |
| --- | --- |
| `setSubtitle(subtitle: String?)` | 说明，≤256 |
| `setBody(body: String?)` | 正文，≤4096，卡片上最多两行 |
| `setImage(image: IslandImage?)` | 左侧图片 |
| `setValue(value: CardValue?)` | 标题右侧放大显示的一项 |
| `setTag(tag: CardTag?)` | 说明后面的小标签 |
| `setTitleMark(mark: IslandImage?)` | 标题后的小图（如完成时的对勾） |
| `addButton(button)` / `setButtons(list)` | 添加一个 / 替换全部；四类按钮均可用 |
| `build()` | 按钮种类或数量超限、编号重复时抛 `IllegalArgumentException` |

只读属性：`title`、`subtitle`、`body`、`image`、`value`、`tag`、`titleMark`。

```kotlin
CardValue.text(text: String, color: Int? = null, icon: IslandImage? = null) // ≤32
CardValue.countdown(endAtMillis: Long)
CardValue.stopwatch(startedAtMillis: Long)

CardTag(text: String?, icon: IslandImage? = null) // 文字 ≤32；两者皆 null 抛异常
```

## 5.4 进度 `ProgressCard`

左侧图片，标题（右侧自动显示百分比），说明与正文，底部一条进度条；可分段并写阶段名，也可带一个随进度移动的小图。适用于外卖、打车、下载、上传。

| 方法 | 说明 |
| --- | --- |
| `setSubtitle` / `setBody` / `setImage` | 同通用卡片（正文在卡片上显示一行） |
| `setProgress(fraction: Float)` | 确定的进度，0~1 |
| `setIndeterminate()` | 进度不确定：亮条来回移动 |
| `setLabels(start: String?, end: String?)` | 进度条两端文字，各 ≤32；**与阶段名互斥** |
| `setStages(stages: List<String>)` | 阶段名 2~16 个（空列表即清除），各 ≤32。按阶段数平均分段、分界处画节点；≥3 个时写在对应节点下方，2 个时写在两端 |
| `setMarker(marker: IslandImage?)` | 随进度移动的小图（骑手、车辆），显示在强调色圆形底上 |
| `addButton` / `setButtons` | 四类按钮均可用 |
| `build()` | 未设进度也未设不确定；阶段名与两端文字同时设；不确定时设了阶段名；按钮超限 → 抛异常 |

只读属性：`title`、`subtitle`、`body`、`image`、`fraction: Float?`（`null` 表示不确定）、`startLabel`、`endLabel`、`stages`、`marker`。

## 5.5 强调 `EmphasisCard`

一张卡里最要紧的一串码或一段计时放大显示。

- **码**（`EmphasisValue.code`）：标题作为上方一行小字写明是什么（如「取件码」），码放大写在下方，说明与正文写在码下面。
- **计时**（倒计时、正计时、已暂停）：左侧图片（未设置时为计时符号），标题与说明写在放大的时间上方，正文写在下面，右侧可放 `TimerControl` 与圆形图标按钮。

| 方法 | 说明 |
| --- | --- |
| `setSubtitle` / `setBody` / `setImage` | 同通用卡片 |
| `addControl(control: TimerControl)` | 计时控制按钮，**仅计时可用**，按加入顺序排列 |
| `addButton` / `setButtons` | 四类按钮均可用 |
| `build()` | 码设置了控制按钮，或按钮超限 → 抛异常 |

只读属性：`title`、`value`、`subtitle`、`body`、`image`、`controls`。

```kotlin
EmphasisValue.code(text: String)                       // ≤32
EmphasisValue.countdown(endAtMillis: Long)             // 到点停在 00:00
EmphasisValue.stopwatch(startedAtMillis: Long)
EmphasisValue.paused(durationMillis: Long)             // 已暂停，静止显示；mm:ss，满一小时 h:mm:ss；不可为负
// val isTimer: Boolean
```

## 5.6 明细 `DetailsCard`

通用卡片的排布，底部并排若干格（上方名称、下方数值），如违章的车牌与时间、电影的场次与座位。

| 方法 | 说明 |
| --- | --- |
| `setSubtitle` / `setBody` / `setImage` | 同通用卡片 |
| `addDetail(detail: CardDetail)` / `addDetail(label: String, value: String)` | 添加一格明细 |
| `setTag` / `setTitleMark` | 同通用卡片 |
| `addButton` / `setButtons` | 四类按钮均可用 |
| `build()` | 明细不在 1~6 格，或按钮超限 → 抛异常 |

只读属性：`title`、`subtitle`、`body`、`image`、`details`、`tag`、`titleMark`。`CardDetail(label: String, value: String)`，名称与数值各 ≤32。

## 5.7 状态 `StatusCard`

左侧图片，标题与说明，右侧放大一项数值或正计时，底部可带一条电量式水平条；正文写在下方，最多两行。适用于设备连接、运行状态。

| 方法 | 说明 |
| --- | --- |
| `setSubtitle` / `setBody` / `setImage` | 同通用卡片 |
| `setValue(value: StatusValue?)` | 右侧放大显示的一项 |
| `setLevel(level: Float?)` | 底部水平条比例，0~1 |
| `setStopButton(show: Boolean)` | 显示红色停止圆钮，点击后 `onAction` 收到 `StatusCard.ACTION_STOP`（`"stop"`） |
| `addButton` / `setButtons` | 四类按钮均可用 |
| `build()` | 按钮超限 → 抛异常（停止圆钮**计入**圆形按钮上限） |

只读属性：`title`、`subtitle`、`body`、`image`、`value`、`level`、`stopButton`。伴生常量 `const val ACTION_STOP: String = "stop"`。

```kotlin
StatusValue.text(text: String)              // ≤32，如「85%」「已连接」
StatusValue.stopwatch(startedAtMillis: Long)
```

## 5.8 大图 `PictureCard`

标题与一行正文，下方一张铺满卡片宽度的大图（最高约 140dp，超出部分居中裁切）。只有一个文字按钮时，按钮显示在标题右侧；锁屏只显示标题时不显示大图。

| 方法 | 说明 |
| --- | --- |
| `setBody(body: String?)` | 正文，≤4096，卡片上显示一行 |
| `addButton` / `setButtons` | 可用 `TextButton`、`BarIconButton`、`ToggleButton`；**不可用** `IconButton` |
| `build()` | 用了圆形图标按钮，或按钮超限 → 抛异常 |

构造方法 `PictureCard.Builder(title: String, picture: IslandImage)`，`picture` **须为** `IslandImage.picture`。只读属性：`title`、`picture`、`body`。

## 5.9 音乐 `MediaCard`

左侧封面，歌名与歌手，一行歌词，播放按键与进度条。进度由星河岛按播放状态与速度自行推进；播放按键排在右侧或歌词下方，由用户在星流「星河岛歌词」页选的「音乐卡片样式」决定，应用无需处理。**不接受其他按钮。**

| 方法 | 说明 |
| --- | --- |
| `setArtist(artist: String?)` | 歌手，≤256 |
| `setCover(cover: IslandImage?)` | 封面，须为 `IslandImage.picture`；`null` 时显示音符占位 |
| `setPlaying(playing: Boolean)` | 是否正在播放（决定播放键图形与进度是否走动），默认 `false` |
| `setProgress(durationMillis: Long, positionMillis: Long, atMillis: Long = now, speed: Float = 1f)` | 总时长 > 0；位置在 0~总时长；`atMillis` > 0；速度 -16~16 |
| `setLyric(lyric: String?)` | 当前一句歌词，≤512；`null` 时歌词行留空 |
| `addControl(control: MediaControl)` | 只加入实际支持的播放操作；未加入的按键不可操作 |
| `setSeekable(seekable: Boolean)` | 进度条可拖动，松手位置由 `onSeek` 交给应用。**须先设置播放进度** |
| `build()` | 可拖动但未设播放进度 → 抛异常 |

构造方法 `MediaCard.Builder(title: String)`，`title` 为歌名，≤128。只读属性：`title`、`artist`、`cover`、`playing`、`durationMillis: Long?`、`positionMillis: Long?`、`positionAtMillis: Long?`、`playbackSpeed: Float`、`lyric`、`controls: Set<MediaControl>`、`seekable`。

> 用户在星流中关闭「星河岛歌词」时音乐卡片不予显示（`[站点]` `develop-api.html` 回调段落）。

## 5.10 消息 `MessageCard`

左侧头像，发送者与最新一条消息（最多两行），可带回复输入框与按钮。

**排位**：按新消息排位——刚送达时优先显示在主岛，停留一段时间后让位。设置了发送时间时，**发送时间变化**才算新的一条；未设置时标题或消息内容变化才算。

| 方法 | 说明 |
| --- | --- |
| `setAvatar(avatar: IslandImage?)` | 头像 |
| `setReplyEnabled(enabled: Boolean)` | 显示回复输入框，用户发送的文字由 `onReply` 交给应用；锁屏时不显示。编辑或发送期间新消息不替换当前回复卡片，未交给应用的文字保留为草稿 |
| `addButton` / `setButtons` | 可用 `TextButton`、`BarIconButton`、`ToggleButton`；**不可用** `IconButton` |
| `build()` | 用了圆形图标按钮，或按钮超限 → 抛异常 |

构造方法 `MessageCard.Builder(sender: String, text: String)`：发送者 ≤128；消息内容 ≤4096，卡片上最多两行。只读属性：`title`（发送者）、`text`、`avatar`、`replyEnabled`。

## 5.11 对称 `MirrorCard`

左右两侧各一个名称（可带标志与小字），中间放大显示比分，下方一行比赛信息。尚无比分时，中间放大显示 `setCenterText` 的文字（如「19:30 开赛」）。**卡片不显示按钮。**

| 方法 | 说明 |
| --- | --- |
| `setCenterText(text: String?)` | 尚无比分时中间放大的文字，≤32；设置后不显示比分 |
| `setDetail(detail: String?)` | 下方一行小字（赛事与比赛阶段），≤128 |
| `build()` | 未设中间文字时两侧缺少比分 → 抛异常 |

构造方法 `MirrorCard.Builder(title: String, left: MirrorSide, right: MirrorSide)`，`title` 不单独显示在卡片上，只用于无障碍读屏。只读属性：`title`、`left`、`right`、`centerText`、`detail`。

```kotlin
MirrorSide(name: String, score: String? = null, logo: IslandImage? = null, note: String? = null)
// 名称、比分、小字各 ≤32；logo 为名称上方的标志
```

## 5.12 回调参数与卡片字段的对应

`onAction` 的 `actionId` 只有三种来源，别记混：

| 来源 | 取值 | 说明 |
| --- | --- | --- |
| 卡片按钮 | 应用自己设置的编号 | 见 [`04-SDK接口参考.md`](04-SDK接口参考.md) §4.9 编号规则 |
| 固定控件 | `pause` / `resume` / `stop` / `prev` / `play_pause` / `next` | `TimerControl`、`MediaControl`、`StatusCard.ACTION_STOP` 的常量值 |
| 自定义业务编号 | 由应用自定，如示例中的 `mark_read` | **不是**系统保留操作，星河岛不会据此自动改变任何状态；需应用在 `onAction` 里自行处理（[`08-示例代码.md`](08-示例代码.md) §8.5） |

其余回调参数：`onReply(activityId, text)` 见 §5.10；`onSeek(activityId, positionMs)` 见 §5.9；`onDismissed` / `onExpanded` / `onCollapsed` / `onEnded` 见 [`04-SDK接口参考.md`](04-SDK接口参考.md) §4.3 与 [`06-生命周期与配额.md`](06-生命周期与配额.md) §6.5。
