# 03 · 通信协议（SDK 内部实现）

> **本章站点未公开**，全部来自 `astraisland-sdk-0.1.2.aar` 的字节码（`javap -p -constants`），包 `com.astraisland.protocol`：`IslandProtocol`、`IslandWire`、`IIslandClient`、`IIslandSession`。
>
> 用途仅限**排障与原理核对**。接入代码请使用 `com.astraisland.sdk` 公开 API，**不要直接拼广播或 Binder**——协议无兼容承诺，版本一变即失效。公开接口见 [`04-SDK接口参考.md`](04-SDK接口参考.md)。

## 3.1 常量（`[SDK]` `IslandProtocol`）

| 常量 | 值 | 说明 |
| --- | --- | --- |
| `PROTOCOL_VERSION` | `7` | 通信版本，收发双方必须一致 |
| `MIN_PROTOCOL_VERSION` | `7` | 最低可接受版本 |
| `SDK_VERSION` | `"0.1.2"` | 与 `IslandClient.SDK_VERSION` 一致 |
| `SYSTEM_UI_PACKAGE` | `"com.android.systemui"` | 注册广播的目标包 |
| `HOST_PACKAGES` | `["com.astraflow.tool"]` | 宿主包名列表 |
| `HOST_METADATA` | `"com.astraisland.HOST_PROTOCOL"` | 宿主 `meta-data` 键，整数值须为 7 |
| `ACTION_REGISTER` | `"com.astraisland.action.REGISTER"` | 注册广播 |
| `ACTION_ISLAND_READY` | `"com.astraisland.action.ISLAND_READY"` | 就绪广播 |
| `EXTRA_CLIENT` / `EXTRA_SOURCE` / `EXTRA_PROTOCOL_VERSION` | `"client"` / `"source"` / `"protocolVersion"` | 注册广播的 extra 键 |
| `ISLAND_READY_SENDER_PERMISSION` | `"android.permission.STATUS_BAR_SERVICE"` | 就绪广播的发送方权限 |

## 3.2 连接时序

```
接入应用                                  星流 / system_server
   │ ① sendBroadcast(ACTION_REGISTER)            │
   │    targetPackage = com.android.systemui     │
   │    extras: client=Binder(IIslandClient)     │
   │            source=<应用包名>                 │
   │            protocolVersion=7                │
   ├────────────────────────────────────────────►│  校验 source / 权限 / 版本
   │ ② 宿主 bindService(应用内 Service)           │
   │◄────────────────────────────────────────────┤  onBind 返回 IIslandSession
   │ ③ session.bind()                            │
   ├────────────────────────────────────────────►│
   │◄──────────── true / false ──────────────────┤
   │ ④ 成功 → linkToDeath → State.READY          │
   │ ⑤ 宿主广播 ACTION_ISLAND_READY               │
   │    （发送方须持有 STATUS_BAR_SERVICE）        │
   │◄────────────────────────────────────────────┤  用于重启后重新注册
```

### 注册广播（`[SDK]` `IslandClient.register()`）

```java
Bundle b = new Bundle();
b.putBinder("client", callbacks(generation));   // IIslandClient.Stub
b.putString("source", context.getPackageName());
b.putInt("protocolVersion", 7);
context.sendBroadcast(new Intent("com.astraisland.action.REGISTER")
        .setPackage("com.android.systemui")
        .putExtras(b));
```

### 就绪广播（`[SDK]` `IslandClient.registerReadyReceiver()`）

| 项 | 值 |
| --- | --- |
| action | `com.astraisland.action.ISLAND_READY` |
| 发送方权限 | `android.permission.STATUS_BAR_SERVICE` |
| 注册方式 | `registerReceiver(receiver, filter, "android.permission.STATUS_BAR_SERVICE", null)`；Android 13+ 追加 `Context.RECEIVER_NOT_EXPORTED`（值为 2） |

> 第三参数是**发送方权限**：只有持系统签名级 `STATUS_BAR_SERVICE` 的进程能投递。接收方应用无需也无法持有该权限（`signature|privileged`）。

## 3.3 Binder 接口（AIDL）

### `IIslandSession` — 应用侧 Binder，供宿主调用

`DESCRIPTOR = com.astraisland.protocol.IIslandSession`

| 事务 | 签名 | 说明 |
| --- | --- | --- |
| `bind()` | `boolean` | 建立会话；`false` 即拒绝 |
| `start(Bundle)` | `int` | 提交内容，返回结果码整数 |
| `end(String id, Bundle outro)` | `int` | 结束单条内容，`outro` 可为空 |
| `endAll()` | `void` | 结束本应用全部内容 |
| `listMine()` | `List<String>` | 仍在岛上的内容编号 |
| `getProtocolVersion()` | `int` | 返回 7 |

`update()` 在 Binder 层**没有独立事务**，与 `start()` 共用——更新就是「同 id 再 start 一次」。

### `IIslandClient` — 宿主侧回调，共 12 个事务

`DESCRIPTOR = com.astraisland.protocol.IIslandClient`

| # | 方法 | 映射到公开回调 |
| --- | --- | --- |
| 1 | `onSessionReady(IIslandSession, int protocolVersion)` | 内部（触发 `bind()`） |
| 2 | `onSessionLost()` | 内部（状态转 `WAITING`） |
| 3 | `onAction(String activityId, String actionId)` | `onAction` |
| 4 | `onExpanded(String activityId, long ts)` | `onExpanded` |
| 5 | `onCollapsed(String activityId, long ts)` | `onCollapsed` |
| 6 | `onDismissedByUser(String activityId, long ts)` | `onDismissed` |
| 7 | `onPromoted(String activityId, long ts)` | **不公开**（空实现） |
| 8 | `onDemoted(String activityId, long ts)` | **不公开**（空实现） |
| 9 | `onExpired(String activityId, long ts)` | `onEnded(EXPIRED)` |
| 10 | `onEndedBySystem(String activityId, long ts)` | `onEnded(REMOVED)` |
| 11 | `onReply(String activityId, String text)` | `onReply` |
| 12 | `onSeek(String activityId, long positionMs)` | `onSeek` |

> `onPromoted` / `onDemoted`（主岛/副岛升降级）在 AIDL 中存在，但 SDK **不对外暴露**，应用无法直接得知自己何时被降为副岛。

### 回调线程与代次

- 所有宿主回调先 `handler.post` 到**主线程**再分发。
- 每次 `connect()` / `register()` 递增 `generation`，回调闭包携带代次；若 `attempt != generation` 或 `desired == false` 或 `session == null`，事件**直接丢弃**。断开后旧会话事件不会串台。

## 3.4 内容线格式（`[SDK]` `IslandWire.encode`）

`IslandActivity` 被编码为一个 `Bundle` 提交给 `start()`。

### 顶层键

| 键（常量名） | 类型 | 说明 |
| --- | --- | --- |
| `id`（`KEY_ID`） | String | 内容编号 |
| `priority`（`KEY_PRIORITY`） | int | 仅 `LOW` / `HIGH` 时写入，见 §3.5 |
| `staleAtWallMs`（`KEY_STALE_AT`） | long | 过时时间 |
| `dismissAfterMs`（`KEY_DISMISS_AFTER`） | long | `afterMillis()` 的时长 |
| `alertOnStart` / `alertOnUpdate` | boolean | 自动展开 |
| `accentColor`（`KEY_ACCENT`） | int | 强调色 |
| `openIntent`（`KEY_OPEN_INTENT`） | Parcelable | `PendingIntent` |
| `compactLeading` / `compactLabel` / `compactTrailing` / `compactTail` | Bundle / String / Bundle / Bundle | 胶囊各 slot |
| `minimal`（`KEY_MINIMAL`） | Bundle | 副岛 slot |
| `expanded`（`KEY_EXPANDED`） | Bundle | 卡片 |
| `lockScreenVisibility` | String | 线值 `PUBLIC` / `REDACTED` / `PRIVATE` |
| `contentDescription` / `landscapeText` | String | 读屏说明、横屏短文字 |
| `postedAtWallMs`（`KEY_POSTED_AT`） | long | 发送时间 |
| `notificationId` / `notificationTag` | int / String | 关联通知 |

`lockScreenVisibility` 线值三态与公开枚举的对应：`PUBLIC→PUBLIC`、`TITLE_ONLY→REDACTED`、`HIDDEN→PRIVATE`——**该对应为推断**（常量名 `VISIBILITY_PUBLIC/REDACTED/PRIVATE` 存在，站点未列映射）。

### slot（胶囊/副岛单元）键

| 键 | 说明 |
| --- | --- |
| `type` | `icon` / `text` / `image` / `ring` / `waveform` / `countdown` / `chronometer` / `busy` |
| `icon` | Bundle，图标 |
| `text` / `color` | String / int |
| `mono` | boolean，等宽（`number()`） |
| `fraction` | float，进度 0~1 |
| `active` | boolean，波形是否跳动 |
| `wallMs` | long，计时基准时刻 |
| `breathing` | boolean，呼吸动画 |

### 图标（`icon`）键

| 键 | 说明 |
| --- | --- |
| `type` | `builtin` / `app` / `bitmap` |
| `builtin` | 内置符号名（`BuiltinSymbol.name()`） |
| `package` | 应用图标来源包名 |
| `bitmap` | Parcelable Bitmap |
| `symbol` | boolean，是否按单色符号样式渲染 |

### 卡片键

| 键 | 说明 |
| --- | --- |
| `template` | `GENERIC` / `PROGRESS` / `EMPHASIS` / `DETAILS` / `STATUS` / `PICTURE` / `MEDIA` / `MESSAGE` / `MIRROR` |
| `title` / `subtitle` / `body` | 文本 |
| `hero` | 左侧/主图 Bundle |
| `progress` | Bundle：`fraction`、`indeterminate`、`startLabel`、`endLabel`、`marker`、`stages` |
| `countdownWallMs` / `chronometerWallMs` / `pausedMs` | long，计时三态 |
| `emphasis` | String，强调卡片的码 |
| `details` | 列表，每项 `label` / `value` |
| `mirror` | Bundle：`leftName`、`leftScore`、`leftLogo`、`leftNote`、`rightName`、`rightScore`、`rightLogo`、`rightNote`、`center`、`detail` |
| `actions` | 列表，每项见下 |
| `playing` / `durationMs` / `positionMs` / `positionAtWallMs` / `speed` | 音乐播放状态与进度 |
| `lyricsLine` | String，当前歌词 |
| `reply` / `seekable` | boolean |
| `value` / `valueColor` / `valueIcon` | 右侧放大项 |
| `level` | float，状态卡水平条 |
| `tag` | Bundle：`text`、`icon` |
| `titleMark` | Bundle，标题后小图 |
| `buttonLayout` | Bundle，见下（0.1.2 新增） |

### 按钮键

| 键 | 说明 |
| --- | --- |
| `id` / `label` | 编号、文字 |
| `icon` | 图标 Bundle |
| `destructive` / `primary` | 样式（对应 `ButtonStyle`） |

> 这是 0.1.2 相对 0.1.1 唯一的线格式新增；公开用法见 [`04-SDK接口参考.md`](04-SDK接口参考.md) §4.9。

### 收尾（`outro`）键

`success`（boolean）、`text`（String）。

## 3.5 结果码与优先级整数（`[SDK]` `IslandProtocol`）

| 常量 | 值 | 对应 `IslandResult` |
| --- | --- | --- |
| `RESULT_OK` | 0 | `OK` |
| `RESULT_NO_PERMISSION` | 1 | `NO_PERMISSION` |
| `RESULT_SOURCE_DISABLED` | 2 | `SOURCE_DISABLED` |
| `RESULT_KIND_DISABLED` | 3 | `KIND_DISABLED` |
| `RESULT_QUOTA_EXCEEDED` | 4 | `QUOTA_EXCEEDED` |
| `RESULT_RATE_LIMITED` | 5 | `RATE_LIMITED` |
| `RESULT_ICON_REJECTED` | 6 | `IMAGE_REJECTED` |
| `RESULT_INVALID` | 7 | `INVALID` |
| `RESULT_BUSY` | 8 | `BUSY` |
| `RESULT_NOT_CONNECTED` | 9 | `NOT_CONNECTED` |

> 线上把图片被拒叫 `ICON_REJECTED`，公开枚举叫 `IMAGE_REJECTED`，同一件事。结果语义与处置见 [`07-错误码与排查.md`](07-错误码与排查.md) §7.1。

| 优先级 | 值 | 说明 |
| --- | --- | --- |
| `PRIORITY_LOW` | 30 | 对应 `Priority.LOW` |
| `PRIORITY_HIGH` | 60 | 对应 `Priority.HIGH`，外部应用最高档 |

> 协议里**只有这两个整数**：`Priority.DEFAULT` 不写 `priority` 键（没有对应的默认值常量），宿主按卡片种类取默认排位。

## 3.6 保留按钮编号（`[SDK]` `RESERVED_ACTION_IDS`）

协议侧常量：`ACTION_PAUSE="pause"`、`ACTION_RESUME="resume"`、`ACTION_STOP="stop"`、`ACTION_TOGGLE="toggle"`、`ACTION_PREV="prev"`、`ACTION_PLAY_PAUSE="play_pause"`、`ACTION_NEXT="next"`。

这 7 个编号被固定控件占用，自定义按钮不得使用；公开侧规则见 [`04-SDK接口参考.md`](04-SDK接口参考.md) §4.9「编号规则」。
