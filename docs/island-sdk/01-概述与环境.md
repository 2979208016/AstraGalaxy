# 01 · 概述与环境

> 来源：`[站点]` <https://astraflow.cc/island/>、`product-overview.html`、`develop-overview.html`、`download.html`、`develop-changelog.html`；`[SDK]` `astraisland-sdk-0.1.2.aar`

## 1.1 平台定位

星河岛在前置摄像头周围显示实时信息。音乐播放、来电、计时、外卖配送与导航等事项以胶囊形态常驻屏幕顶端，点按即可展开为完整卡片。应用通过星河岛 SDK 接入，以统一样式呈现自身的进行中事项。

内容来自三个渠道：

1. 星流内置内容（音乐与歌词、聊天消息）；
2. 手机系统提供的实时服务（来电、充电、计时器、外卖、打车、导航等）；
3. 通过星河岛 SDK 接入的第三方应用（下载进度、健身记录、赛事比分等）。

星河岛是**独立的显示界面**，不属于任何手机品牌的系统功能。应用只负责提供内容；排版、动效与显示规则由星河岛决定。

## 1.2 三种显示形态

| 形态 | 说明 |
| --- | --- |
| 胶囊 | 默认形态。以摄像头为中心向两侧延伸，显示事项中最重要的一至两项信息 |
| 副岛 | 多个事项同时进行时，次要事项以圆形显示在主岛两侧，点按可切换为主岛 |
| 展开卡片 | 点按胶囊后展开，呈现完整信息、进度与操作按钮 |

同一事项在屏幕顶端只显示一次，三种形态之间连续过渡（`design-capsule.html`）。胶囊与副岛的排布规则见 [`05-卡片数据结构.md`](05-卡片数据结构.md) §5.1。

## 1.3 九套模板（选择用）

选型只看这张表；每套模板的字段、默认值与互斥规则集中在 [`05-卡片数据结构.md`](05-卡片数据结构.md)。

| 模板 | 类名 | 适用场景 |
| --- | --- | --- |
| 通用 | `GenericCard` | 一般提醒与状态说明：标题、说明与正文，标题右侧可放大一项数值或走动的时间 |
| 进度 | `ProgressCard` | 配送、出行、下载、上传、安装：底部进度条可分阶段并标注名称，图标随进度移动 |
| 强调 | `EmphasisCard` | 取件码、取餐码、倒计时与正计时：以大字号显示一串码或一段计时 |
| 明细 | `DetailsCard` | 票务、预约、课程、违章：底部并列多项名称与数值 |
| 状态 | `StatusCard` | 设备连接、电量、运行状态：右侧放大数值，底部可带水平条 |
| 大图 | `PictureCard` | 以图片为主的事项：图片铺满卡片宽度 |
| 音乐 | `MediaCard` | 音乐、播客、有声书：封面、歌词、播放按键与可拖动的进度条 |
| 消息 | `MessageCard` | 即时消息：头像、发送人、最新消息与回复栏 |
| 对称 | `MirrorCard` | 赛事比分与对阵：两侧名称与中间的放大比分 |

视觉规范见 `design-templates.html`；精确的尺寸、圆角与字号站点未给出数值（见 §1.10）。

## 1.4 版本

| 项目 | 值 | 来源 |
| --- | --- | --- |
| SDK 版本 | `0.1.2`（`IslandClient.SDK_VERSION`、`IslandProtocol.SDK_VERSION`） | `[站点]` `[SDK]` |
| 通信版本 | `7`（`IslandClient.PROTOCOL_VERSION` / `IslandProtocol.PROTOCOL_VERSION`） | `[站点]` `[SDK]` |
| 最低可接受通信版本 | `7`（`MIN_PROTOCOL_VERSION`） | `[SDK]` |
| 宿主元数据 | `com.astraisland.HOST_PROTOCOL` 须为 `7` | `[SDK]` 见 [`02-接入与清单.md`](02-接入与清单.md) §2.3 |

**版本纪律**：接入库与星流必须同为通信版本 7，`低于或高于 7 的版本均不建立连接`（`[站点]` `develop-limits.html`）。历史版本差异见 [`09-版本变更记录.md`](09-版本变更记录.md)。

## 1.5 环境要求

### 接入应用（`[站点]` `develop-overview.html`）

| 项目 | 要求 |
| --- | --- |
| 最低系统 | Android 8.0（API 26）及以上 |
| compileSdk | 26 及以上（官方示例使用 36） |
| Java | 17 |
| Kotlin 工程 | Kotlin 2.1 及以上 |
| 依赖 | 仅 Kotlin 标准库；无需额外混淆规则 |

### 用户设备（`[站点]` `develop-overview.html`）

| 项目 | 要求 |
| --- | --- |
| 系统 | Android 15 及以上 |
| 宿主 | 已安装并启用星流（`com.astraflow.tool`） |
| OPPO / 一加 / realme | 还需安装并启用星流官方插件「流体云事件接入」，插件启用前星河岛不显示 |

### 系统服务支持范围（`[站点]` `product-system.html`、`index.html`）

| 系统 | 状态 |
| --- | --- |
| ColorOS 16（OPPO、一加、realme） | 系统流体云已支持 |
| ColorOS 17 | 系统流体云已支持 |
| ColorOS 15 | 系统流体云基本可用 |
| 其他品牌 | 需由该品牌系统自行实现接入 |

## 1.6 依赖引入

### Gradle（Kotlin DSL，`[站点]` `develop-quickstart.html`）

```kotlin
dependencies {
    implementation(files("libs/astraisland-sdk-0.1.2.aar"))
}
```

### 纯 Java 工程

还需添加 Kotlin 标准库（站点给定版本）：

```kotlin
implementation("org.jetbrains.kotlin:kotlin-stdlib:2.1.20")
```

### 官方示例工程的构建配置（`[SDK]` `astraisland-sdk-sample-0.1.2/app/build.gradle.kts`）

```kotlin
android {
    namespace = "com.example.islandsample"
    compileSdk = 36
    defaultConfig {
        applicationId = "com.example.islandsample"
        minSdk = 26
        targetSdk = 36
        versionCode = 1
        versionName = "1.0"
    }
    compileOptions {
        sourceCompatibility = JavaVersion.VERSION_17
        targetCompatibility = JavaVersion.VERSION_17
    }
    kotlinOptions { jvmTarget = "17" }
}

dependencies {
    implementation(files("libs/astraisland-sdk-0.1.2.aar"))
}
```

根工程使用 Android Gradle 插件 `8.9.3`、Kotlin 插件 `2.1.20`（`[SDK]` `build.gradle.kts`）。工程可直接用 Android Studio 打开，`app/libs/` 内已放同一份 AAR。

## 1.9 平台不开放的能力（`[站点]` `develop-limits.html`）

- 导航与通话模板，以及导航排位。
- 将内容标记为独占。
- 动态图标与自定义动画。
- 由应用自行绘制整张卡片。
- 冒充系统提示的内置符号（来电、麦克风、摄像头、录屏、人脸与解锁）。
